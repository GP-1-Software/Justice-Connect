# Legal Consultation & Case Management Platform 🏛️⚖️

منصة ويب شاملة تربط المحامين مع المستخدمين (العملاء)، لتقديم الاستشارات القانونية، إدارة القضايا، التواصل، والدفع الإلكتروني - مدعومة بالذكاء الاصطناعي.

## 🚀 المزايا الرئيسية

### للعملاء
- 🔍 **البحث الذكي**: ابحث عن المحامي المناسب حسب التخصص والموقع
- 📅 **حجز المواعيد**: نظام حجز سهل للاستشارات الحضورية والأونلاين
- 💬 **تواصل آمن**: شات مشفر ومكالمات صوتية/فيديو
- 📂 **إدارة القضايا**: تابع قضاياك بشكل كامل
- 💳 **دفع آمن**: نظام دفع إلكتروني موثوق

### للمحامين
- 👨‍⚖️ **بروفايل احترافي**: عرض خبراتك وشهاداتك
- 📆 **إدارة المواعيد**: تقويم ذكي لإدارة وقتك
- 📁 **إدارة الملفات**: رفع وتنظيم مستندات القضايا
- 📊 **إحصائيات**: تتبع أدائك وتقييماتك

## 🤖 مزايا الذكاء الاصطناعي

- 📑 **تحليل المستندات**: تحليل تلقائي للعقود والمستندات القانونية
- 🤖 **مساعد قانوني ذكي**: إجابات فورية على الأسئلة القانونية
- 📊 **توقع النتائج**: تقدير نسبة نجاح القضايا
- ✨ **توصية المحامي المثالي**: اقتراحات ذكية بناءً على احتياجاتك

## 🛠️ التقنيات المستخدمة

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Font**: Cairo (Google Fonts)

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js (v16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **تثبيت الحزم**
```bash
npm install
```

2. **تشغيل المشروع في وضع التطوير**
```bash
npm run dev
```

3. **بناء المشروع للإنتاج**
```bash
npm run build
```

4. **معاينة النسخة الإنتاجية**
```bash
npm run preview
```
