# 🏛️ Justice Connect - منصة العدالة القانونية

## 📋 نظرة عامة على المشروع

**Justice Connect** هي منصة قانونية شاملة تربط بين العملاء والمحامين في فلسطين، وتوفر حلول قانونية متكاملة من خلال واجهة حديثة وسهلة الاستخدام. المنصة تدعم اللغة العربية بالكامل وتوفر نظام إدارة قضايا متقدم مع ذكاء اصطناعي قانوني.

### 🎯 الهدف من المشروع
- تسهيل الوصول إلى الخدمات القانونية للمواطنين
- توفير منصة احترافية للمحامين لإدارة قضاياهم
- استخدام الذكاء الاصطناعي لتقديم استشارات قانونية أولية
- تنظيم وأتمتة العمليات القانونية والإدارية

---

## 👥 أنواع المستخدمين

### 1. 🧑‍💼 العميل (Client)
- إنشاء حساب والبحث عن محامين متخصصين
- إنشاء قضايا قانونية وإدارتها
- التواصل مع المحامي المعين
- متابعة تطور القضية وجلساتها
- استخدام الذكاء الاصطناعي القانوني (Justice AI)

### 2. ⚖️ المحامي (Lawyer)
- عرض الملف الشخصي والتخصصات
- إدارة القضايا المعينة
- إضافة تحديثات ومستندات للقضايا
- جدولة المواعيد والاجتماعات
- إنشاء وإرسال الفواتير
- استخدام الذكاء الاصطناعي للمساعدة القانونية

### 3. 👨‍💼 المدير (Admin)
- إدارة المستخدمين (عملاء ومحامين)
- مراجعة والموافقة على تسجيل المحامين
- إدارة القضايا والإشراف عليها
- عرض الإحصائيات والتقارير
- إدارة تذاكر الدعم الفني

## ⭐ الميزات الرئيسية

### 🔐 نظام المصادقة والأمان
- **تسجيل الدخول والحساب**: نظام تسجيل آمن مع Supabase Authentication
- **أنواع حسابات متعددة**: عميل، محامي، مدير
- **التحقق من المحامين**: نظام موافقة من الإدارة قبل تفعيل حساب المحامي
- **إدارة الجلسات**: JWT tokens وإدارة آمنة للجلسات
- **رقم الهوية الفلسطيني**: التحقق من صحة الهوية (9 أرقام)

### 📱 لوحة التحكم (Dashboard)

#### لوحة العميل:
- 📊 إحصائيات القضايا (نشطة، معلقة، مغلقة)
- 📅 المواعيد القادمة
- 🔔 الإشعارات الحديثة
- 📈 رسوم بيانية توضيحية
- 🔍 البحث السريع عن المحامين

#### لوحة المحامي:
- 📊 إحصائيات القضايا والعملاء
- 💰 الدخل والفواتير
- 📅 المواعيد والاجتماعات
- ⏰ المهام والجلسات القادمة
- 📈 تحليلات الأداء

#### لوحة المدير:
- 📊 إحصائيات المنصة الشاملة
- 👥 إدارة المستخدمين
- ✅ طلبات التحقق من المحامين
- 🎫 تذاكر الدعم
- 📈 تقارير مفصلة

### 🗂️ نظام إدارة القضايا

#### للعملاء:
- ✅ **إنشاء قضية جديدة**: نموذج تفصيلي مع اختيار نوع القضية
- 📋 **قائمة القضايا**: عرض جميع القضايا مع الفلترة والبحث
- 🔍 **تفاصيل القضية**: 
  - نظرة عامة على القضية
  - الجدول الزمني للأحداث
  - المهام والإجراءات
  - الملفات والمستندات
  - الملاحظات والتعليقات
- 👨‍⚖️ **معلومات المحامي**: بيانات المحامي المعين
- 📊 **تقارير القضية**: توليد تقارير شاملة بالذكاء الاصطناعي
- ⚠️ **حالات القضية**: pending, active, closed, rejected

#### للمحامين:
- ➕ **إضافة قضايا**: إنشاء قضايا لعملاء جدد أو موجودين
- 📝 **إدارة معلومات العميل**: إضافة وتحديث بيانات العملاء
- 📅 **الجدول الزمني**: إضافة أحداث وتحديثات للقضية
- 📎 **إدارة المستندات**: رفع وتنظيم الملفات
- ✏️ **الملاحظات الخاصة**: ملاحظات مخفية عن العميل
- ✅ **إدارة المهام**: إنشاء وتتبع المهام
- 📅 **جدولة الاجتماعات**: تحديد مواعيد مع العملاء

### 🔍 البحث عن المحامين

- 🔎 **بحث متقدم**: البحث حسب التخصص، المدينة، سنوات الخبرة
- 🌟 **عرض الملفات الشخصية**: معلومات تفصيلية عن كل محامي
- 📊 **الإحصائيات**: عدد القضايا، التقييمات، سنوات الخبرة
- 📞 **معلومات الاتصال**: البريد الإلكتروني، الهاتف، المدينة
- 📜 **رقم الترخيص**: التحقق من مزاولة المهنة

### 📅 نظام المواعيد والاجتماعات

- 📆 **حجز المواعيد**: العملاء يمكنهم حجز مواعيد مع المحامين
- 🔄 **إدارة المواعيد**: قبول، رفض، إعادة جدولة
- 🎥 **روابط الاجتماعات**: دعم Google Meet, Zoom, Microsoft Teams
- 🔔 **التذكيرات**: إشعارات تلقائية قبل الموعد
- 📊 **التقويم**: عرض جميع المواعيد في تقويم شهري

### 💬 نظام المراسلة

- 💬 **دردشة مباشرة**: تواصل فوري بين العميل والمحامي
- 📎 **إرسال الملفات**: مشاركة المستندات في المحادثة
- 🔔 **إشعارات فورية**: تنبيهات الرسائل الجديدة
- 📱 **تصميم متجاوب**: واجهة دردشة حديثة
- ⏰ **الرسائل في الوقت الفعلي**: باستخدام Supabase Realtime

### 💰 نظام الفواتير والمدفوعات

#### للمحامين:
- 📝 **إنشاء فواتير**: فواتير تفصيلية للعملاء
- 💳 **حالات الدفع**: pending, paid, overdue
- 📊 **تتبع الدخل**: إحصائيات الفواتير والأرباح

#### للعملاء:
- 👀 **عرض الفواتير**: قائمة بجميع الفواتير
- 💳 **الدفع الإلكتروني**: خيارات دفع متعددة
- 📥 **تحميل الفواتير**: حفظ نسخة PDF
- 🔔 **تنبيهات الفواتير**: إشعارات الفواتير المستحقة

### 🤖 الذكاء الاصطناعي القانوني (Justice AI)

- 💬 **محادثة ذكية**: استشارات قانونية أولية فورية
- 📚 **قاعدة معرفية**: معلومات قانونية شاملة
- 🎯 **توصيات ذكية**: اقتراحات بناءً على نوع القضية
- 📝 **حفظ المحادثات**: تاريخ كامل للاستشارات
- 🔄 **تكامل مع القضايا**: ربط الاستشارات بالقضايا

### 🔔 نظام الإشعارات

- 📬 **إشعارات فورية**: تحديثات لحظية للأحداث المهمة
- 🔕 **إعدادات التحكم**: تخصيص أنواع الإشعارات
- 📱 **إشعارات متعددة المنصات**: Email + In-app
- ⏰ **جدولة الإشعارات**: تذكيرات بالمواعيد والجلسات
- 📊 **مركز الإشعارات**: عرض جميع الإشعارات في مكان واحد

### 🎫 نظام الدعم الفني

- 📝 **تذاكر الدعم**: إنشاء طلبات دعم فني
- 💬 **التواصل مع الإدارة**: رد مباشر من فريق الدعم
- 🏷️ **أولويات مختلفة**: low, medium, high, urgent
- 📊 **حالات التذاكر**: open, in_progress, resolved, closed
- 🔄 **تتبع الحالة**: متابعة تطور التذكرة

### 👤 إدارة الملف الشخصي

- ✏️ **تحديث البيانات**: تعديل المعلومات الشخصية
- 📸 **صورة الملف الشخصي**: رفع وتحديث الصورة
- 🔐 **تغيير كلمة المرور**: أمان محسّن
- 🗑️ **حذف الحساب**: طلب حذف البيانات الشخصية
- 🌐 **اللغة والإعدادات**: تخصيص تجربة المستخدم

### 📊 التقارير والتحليلات

- 📈 **تقارير القضايا**: تقارير شاملة بالذكاء الاصطناعي
- 💰 **تقارير مالية**: إحصائيات الدخل والمصروفات
- 👥 **إحصائيات المستخدمين**: أعداد وتوزيع المستخدمين
- 📊 **رسوم بيانية**: تصورات تفاعلية للبيانات
- 📥 **تصدير البيانات**: Excel, PDF, CSV

## 🚀 كيفية البدء

### المتطلبات الأساسية:
```bash
Node.js >= 18.x
npm >= 9.x
Supabase Account
OpenAI API Key
```

### التثبيت:

```bash
# 1. استنساخ المشروع
git clone https://github.com/GP-1-Software/Justice-Connect.git
cd Justice-Connect

# 2. تثبيت dependencies للـ frontend
npm install

# 3. تثبيت dependencies للـ backend
cd backend
npm install

# 4. إعداد متغيرات البيئة
# إنشاء ملف .env في المجلد الرئيسي
cp .env.example .env

# إنشاء ملف .env في مجلد backend
cd backend
cp .env.example .env

# 5. تشغيل قاعدة البيانات
# تطبيق SQL schemas من مجلد server/supabase/

# 6. تشغيل المشروع
# في terminal 1 (Frontend)
npm run dev

# في terminal 2 (Backend)
cd backend
npm start
```

### متغيرات البيئة المطلوبة:

#### Frontend (.env):
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

#### Backend (backend/.env):
```env
SUPABASE_URL=your_supabase_url
SUPABASE_SERVICE_KEY=your_supabase_service_key
OPENAI_API_KEY=your_openai_api_key
PORT=5000
```
